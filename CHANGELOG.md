## [1.0.0] - 2026-11-23

### Added

- Browser first-person liminal-horror prototype “THRESHOLD” with six levels (Lobby, Poolrooms, Aqueduct, Floor 8, The Deep End, The Hill).
- `WebGPURenderer` (three.js r187) path with WebGL2 fallback, TSL materials, clustered lighting, post-processing stack, procedural audio, and localStorage saves.
- Static dev server (`serve.py`) and vendored Three.js runtime files under `vendor/three/`.
